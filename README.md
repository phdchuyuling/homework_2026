# BMI 計算作業

## 執行環境

- Python 3
- 僅使用 Python 標準功能，不需安裝第三方套件
- 在命令列切換到本資料夾後執行：

```bash
python3 BMI.py
```

Windows 可使用：

```powershell
python BMI.py
```

依提示輸入體重（公斤）與身高（公分）。程式不依賴電腦上的絕對路徑，也不需額外環境變數。

## 計算方式

BMI = 體重（公斤） ÷ 身高（公尺）²

程式會檢查輸入是否為數字且大於 0，並顯示 BMI（四捨五入至小數點後一位）和成人分類。分類採台灣成人常用參考區間：低於 18.5 為體重過輕；18.5 至未滿 24 為健康體重；24 至未滿 27 為體重過重；27 以上為肥胖。此分類僅供參考，不作為醫療診斷。
