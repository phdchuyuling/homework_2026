# FocusFlow｜進階待辦事項管理系統

## 開啟方式
雙擊 `index.html`，使用 Chrome、Edge 或 Safari 開啟，不需安裝套件，也不需連網。

## 功能
- 新增、編輯、完成、刪除任務
- 四種優先程度：緊急、高、中、低
- 工作、學校、生活、個人四類
- 截止日期、今日到期、逾期提醒標籤、未來計畫
- 多個子任務及完成進度
- 關鍵字搜尋、分類與優先級篩選、三種排序
- 全部、未完成、已完成檢視
- 任務總數、待完成數、緊急數、完成率統計
- JSON 匯出與匯入備份
- 匯入會依任務 ID 合併：保留備份中不存在的本機任務，同 ID 任務以備份版本更新；無效 JSON 不會套用
- 手機與電腦自適應介面
- localStorage 自動儲存；第一次開啟可點「加入示範資料」
- 舊版 `codex-todo-v1` 資料可自動讀入

## 測試步驟
1. 新增緊急任務，設定今天到期，檢查「緊急事項」「今日到期」和統計卡片。
2. 新增子任務，逐項勾選，確認進度變化。
3. 使用搜尋、分類、優先程度及排序。
4. 編輯、完成及刪除任務，重新整理網頁確認資料仍在。
5. 匯出 JSON、再匯入，確認本機其他任務仍保留、同 ID 任務使用備份內容。
6. 嘗試匯入格式錯誤的 JSON，確認顯示錯誤且既有資料不變。

## 注意
資料保存在**目前瀏覽器與來源**的本機儲存空間，並非雲端同步；不同電腦請透過 JSON 備份搬移。匯入採合併，同 ID 任務會以備份版本更新，重要資料仍建議先匯出備份。瀏覽器若限制 `file://` 的 localStorage，建議用 VS Code Live Server 開啟。此專案不會發送系統通知，逾期提示僅在頁面內顯示。
