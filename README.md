# BMI 計算程式作業

本作業為德霖資工 1A、2A 同學的作業繳交說明。

## 作業要求

1. **作業名稱：** BMI 計算程式
2. **檔名：** `BMI`，並依程式語言加上正確副檔名。例如：`BMI.py`。
3. **可攜式架構：** 程式應能在不同電腦環境執行；避免使用僅適用於自己電腦的絕對路徑或環境設定，並一併提供程式執行所需的檔案與依賴說明。
4. **Fork：** 請先 Fork 本作業儲存庫至自己的 GitHub 帳號，再在自己的 Fork 中新增作業檔案。
5. **PR 繳交：** 完成並推送作業後，向本儲存庫的 `main` 分支建立 Pull Request（PR）作為繳交。建立 PR 時，請依 PR 內的「作業繳交檢核表」逐項確認並勾選。PR 標題請註明作業名稱，內容請提供程式執行方式及必要依賴。

> **個人資料提醒：** 請勿在 PR 標題、內容、檔名或作業檔案中公開姓名、學號、電話、地址等個人資料。若課程需要身分核對，請使用老師指定的私密管道提供。

## BMI.py 執行方式

本次提交的 `BMI.py` 使用 Python 3，無需安裝第三方套件。請在儲存庫根目錄執行：

```bash
python3 BMI.py
```

程式依序要求輸入體重（kg）及身高（cm），並依 `BMI = 體重kg / (身高cm / 100)^2` 顯示結果至小數點後兩位。空白、非數值、零、負數、`NaN`、`Infinity` 及無法合理計算的數值都會被拒絕並要求重新輸入。

## 繳交流程

1. 登入 GitHub，Fork 本儲存庫。
2. 在自己的 Fork 新增 BMI 程式，並依規定命名檔案。
3. Commit 並 Push 變更至自己的 Fork。
4. 從自己的作業分支建立 PR，目標為本儲存庫的 `main` 分支。
5. 完成 PR 內的「作業繳交檢核表」，確認檔案及執行說明正確且未包含個人資料後送出。
