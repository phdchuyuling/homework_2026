# 象棋 AI 對弈 — 修正版啟動包

## 先執行遊戲
1. 解壓縮整個 ZIP（不要直接在壓縮檔內執行）。
2. 雙擊 USB_PORTABLE_DEV\START_GAME.bat。
3. 若瀏覽器沒有開啟，視窗會保留錯誤訊息；也可直接雙擊 Projects\xiangqi-ai\index.html。

## 用 VS Code 開啟專案
雙擊根目錄 START.bat，會嘗試開啟本機已安裝的 VS Code 與 Projects\xiangqi-ai 專案。
若要直接玩遊戲，請使用 START_GAME.bat，而不是 START.bat。

遊戲為離線 HTML，無需 Python、Node.js、Flutter 或網路。
錯誤記錄在 Logs 資料夾。
